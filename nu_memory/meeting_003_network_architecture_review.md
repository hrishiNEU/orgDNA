# Meeting minutes: Network Architecture Review — VPN standardization

*(Simulated minutes for demo purposes)* · **Recording:** available in meeting archive

**Attendees:** CIO, Network Services lead, Office of Information Security analyst, IT Service Desk manager, campus IT representatives.

**Summary:** Network Services presented the proposal to standardize university remote access on GlobalProtect. Discussion covered: MFA enrollment as a prerequisite for first connection; split-tunnel design (Microsoft 365 and other cloud traffic stays outside the tunnel, protected NUnet traffic goes through it); support-readiness plan with pre-written install guides per platform; and deprecation timeline for legacy per-department VPN appliances.

**Decision:** GlobalProtect approved as the single university VPN, portal at vpn.northeastern.edu. Faculty and staff required to use it for protected resources off campus; students strongly encouraged. Logged as DEC-VPN-01.

**Action items:** Service Desk to publish install guides before announcement. InfoSec to file the security assessment. Network Services to schedule legacy appliance decommissioning. Communications to draft the campus announcement email.
